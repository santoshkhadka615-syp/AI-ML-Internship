# AI-ML-Internship

* Month 2 (Weeks 5-8): Core ML — regression, classification, evaluation, NLP basics

* Month 3 (Weeks 9-12): Neural networks intro, deployment, capstone

# Tech Stack

Python, NumPy, Pandas, Matplotlib/Seaborn, scikit-learn, PyTorch/TensorFlow, Streamlit
